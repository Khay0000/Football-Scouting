# Football Player Scouting Tool

## Question
Which young midfielders in the top 5 European leagues perform like
elite players but are likely undervalued by the market?

## Data sources
- Understat (xG, xA, shots, key passes)
- Transfermarkt dataset (market values, age)

## Tools
Python, Pandas, scikit-learn, Power BI/Tableau
